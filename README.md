# 📊 Advanced Sales Data Analysis & Dynamic Dashboard

## 📝 Project Overview
This project showcases advanced data analysis, dashboard design, and formula modeling using Microsoft Excel. I took a large, unstructured raw sales dataset and transformed it into a clean, highly performant, and insightful sales summary dashboard. 

Instead of traditional pivot tables, this entire project is driven by dynamic formulas to ensure absolute control over data aggregation and real-time report updating.

## 🛠️ Key Features & Technical Skills Demonstrated
* *Advanced SUMIFS & SUMIF Functions:* Implemented multi-criteria logic to dynamically calculate total sales amounts and quantities across multiple intersecting conditions.
* *Logical Cross-Tabulation:* Structured complex summary tables that filter data simultaneously by *Region, Product Category, and Customer Segment*.
* *Granular Performance Tracking:* Developed detailed breakdown tables for individual product segments (e.g., Vests, Tires and Tubes, Touring Bikes) without disrupting the core master sheet.
* *File Performance Optimization:* Structured the workbook in a clean layout to ensure seamless GitHub cloning and fast execution.

## 📊 Data Insights Covered
The dashboard automatically summarizes and breaks down the master sales dataset by:
1. *By Region:* Delta, Giza, Cairo, Canal, Upper
2. *By Category:* Clothing, Components, Accessories, Bikes
3. *By Sales Channel:* Retail, Wholesale, Key Accounts, Door to Door
4. *By Segment:* Consumer vs. Business
