# 📊 Advanced Sales Data Analysis & Dynamic Dashboard

## 📝 Project Overview
This project showcases advanced data analysis and summary reporting using Microsoft Excel. I took a large, unstructured *3-month raw sales dataset* and transformed it into a clean, highly structured, and insightful sales summary dashboard. 

Instead of traditional pivot tables, this entire project is built using dynamic formulas to ensure absolute control over data aggregation.

## 🛠️ Key Features & Formulas Used
* *Advanced SUMIFS & SUMIF Functions:* Implemented multi-criteria logic to dynamically calculate total sales amounts and quantities across multiple intersecting conditions.
* *Logical Cross-Tabulation:* Structured complex tables that filter data simultaneously by *Region, Product Category, and Customer Segment*.
* *Granular Breakdown Tables:* Developed detailed performance tracking for individual product segments (e.g., Vests, Tires and Tubes, Touring Bikes).

## 📊 Data Insights Covered
The dashboard automatically summarizes and breaks down the 3-month sales data by:
1. *By Region:* Delta, Giza, Cairo, Canal, Upper
2. *By Category:* Clothing, Components, Accessories, Bikes
3. *By Sales Channel:* Retail, Wholesale, Key Accounts, Door to Door
4. *By Segment:* Consumer vs. Business
